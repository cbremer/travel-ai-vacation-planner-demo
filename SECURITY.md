# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing an unpatched vulnerability, a credential, personal travel information, or another person's private data.

This project is a static demonstration app. It must not contain real traveler names, contact details, booking confirmations, private lodging information, credentials, or API keys.
